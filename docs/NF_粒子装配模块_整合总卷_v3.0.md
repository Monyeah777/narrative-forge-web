## §1 · 设计总纲与红线

### 1.1 场景

- NF 官网「深空档案馆」：全站深黑底（#050505）、水墨星尘粒子、莫奈《白杨树》系列（Les Peupliers, 1891，春 / 夏 / 秋三态）、像素复古报纸排版、玻璃底片（lantern slide）拖拽面板。
- 核心装置：全站唯一彩色区——名画笔触粒子装配装置。

### 1.2 红线（所有阶段不可违反）

| # | 红线 |
|---|---|
| 1 | 彩页政策：全站唯一彩色 = 笔触装置；其余单色 |
| 2 | 单色纪律：同屏一次一色；春绿 / 夏深绿 / 秋橙金轮转；禁双色 glitch |
| 3 | 哑光印刷感；禁发光（禁 additive / glow / shadowBlur） |
| 4 | 控件只有导航（放映启停为注记级文本，属白名单例外） |
| 5 | 中心树轮廓保持清晰稳定 |
| 6 | 反 boil：禁逐粒子独立抖动；一切运动相干（空间低频 + 时间低频） |
| 7 | 完成 ≠ 停：不存在「静止完成态」 |
| 8 | 不得静默超预算：超预算必须降级或申议并上报 |
| 9 | 拖拽面板：玻璃底片（透明玻璃感，拒毛玻璃） |

### 1.3 设计哲学（一行为纲）

生成 = 大尺度相干运动；存在 = 持续低幅相干流动（涟漪 × 流场 × 脉线逸散）——「作者还在乎」的持续证据。**完成 ≠ 停。**

## §2 · 自动放映总规格（v1.0 定稿）

### 2.1 状态机与时序

- 状态链：`LOAD → INTRO（首幅装配·显影 2.4s）→ DWELL（8–12s，默认 10）→ HANDOVER（2.5–3.5s，默认 3.0）→ DWELL → …`
- 顺序：catalog 固定数组；整轮回首幅；全部参数（dwell / transition / seed / T_idle=30s）入 manifest，运行时不得掷骰。
- 图注：随幅真值更新；交接中段 ≤300ms 换新；aria-live：自动中 off / 停止时 polite。
- 无进度条、无重放按钮。

### 2.2 交互接管（分权表）

| 输入 | 行为 |
|---|---|
| hover | 暂停；离开 +1.5s 恢复 |
| 点击 / 导航 | 进入手动；静置 30s 恢复 |
| 键盘焦点 | 进入即停；仅显式操作恢复 |
| 放映启停（注记级文本） | 持久暂停；不自动恢复（§9-1） |

### 2.3 交接（HANDOVER）语义

边缘先散、核心后散；「B 核最先凝」；过渡管线：排序释放 → 外漂 → 分波 → 软收束 → 弧线流场；**禁 snapAll**（断言）。

### 2.4 无障碍与合规（浓缩）

| 要求 | 机制 |
|---|---|
| WCAG 2.2.2 | 图注级『放映启停』（常驻、持久、不占焦点） |
| APG | 焦点即停、非显式不恢复；hover 即停 |
| reduced-motion | 不轮换、静态、无装配动画；手动切换 = 瞬切或 ≤400ms 淡切 |
| 隐藏即停 | visibilitychange + IntersectionObserver 双通道 |

### 2.5 配套视觉参数（已收编）

- 像素块：哑光实心、整数设备像素对齐、关平滑；尺寸默认 3 设备像素（回退 2）。
- 初始分布：画区中心云（cloud）。
- 画区占比：维持 1.0；保留 ±10% A/B 实验开关（不挪位置）。
- 外围尘埃：见 §5。
- 彩度版本：v1 / v2 保留；v3「降饱和豁免」不纳入构建（§9-3）。

### 2.6 放映性能纪律（数字）

- DWELL 脚本增量 ≤ +1.0ms；轮换 = 持续动效，与粒子预算统一核算；超 → 申议降级（不静默）。

## §3 · 采样与数据层（v2.0 / v2.1 定稿）

### 3.1 管线总览

- 两阶段：主采样（密度校正的种子分布）→ 细化（样本消除 / 蓝噪声松弛）；**禁止裸均匀随机**（历史「全屏均匀噪声」即此问题）。
- 面积元纪律：径向抽样须 `p(r) ∝ r·W(r)`（面积元 r）；默认**拒绝采样**实现；不得用 `p(r) ∝ W(r)`（会中心堆积、外围亏空）。

### 3.2 密度与掩膜

- W(r)：画作权重场；浅色天空区必须给足权重（历史孔洞根因之一）；掩膜 = 画作可见区域，**不得排除浅色区**。
- **W 生效证明闸（P0）**：① W 可视化 ② 径向密度剖面 ③ 计数对账——三件套齐才过闸（防「未落实」复发）。

### 3.3 计数口径（§9-6）

- 归档 50k；快速预览 20–30k；性能应急可降 30k（需日志，不静默）。

### 3.4 进阶项（休眠，按需触发，不阻塞主线）

- 加权样本消除（Yuksel 2015）；Sliced OT 采样（Paulin 2020）；单趟圆填充（Cui 2026）；蓝噪声自适应。

### 3.5 验收

- 径向剖面单调衰减；无中心孔洞；无边缘环（「茧」）；计数对账通过；1:1 对比通过。

## §4 · 时间语义与物理承继（v2.1 / v2.3 定稿）

### 4.1 时间语义（PixiJS v8 · 已核）

| 属性 | 语义 | 60fps 典型值 | 单位 |
|---|---|---|---|
| `ticker.deltaTime` | 帧率无关**倍率**（60fps 基准「帧数」） | ≈ 1.0 | 无量纲 |
| `ticker.deltaMS` | 距上一帧的**真实毫秒** | ≈ 16.67 | ms |

**强制积分规格（唯一合法写法）**：

```js
const FIXED_H = 1 / 60;          // 固定步长（秒）
const FIXED_H_MS = 1000 / 60;    // ≈ 16.6667 ms
const MAX_FRAME_MS = 50;         // 钳制

let accMs = 0;
app.ticker.add((t) => {
  const frameMS = Math.min(t.deltaMS, MAX_FRAME_MS);  // 唯一合法时间源
  accMs += frameMS;
  while (accMs >= FIXED_H_MS) {
    stepPhysics(FIXED_H);        // 定步长；全部系数按 1/60s 锚定
    accMs -= FIXED_H_MS;
  }
  const alpha = accMs / FIXED_H_MS;
  renderInterpolated(alpha);     // 含 M0/M1 叠加 → 写回粒子
});
```

**红线**：❌ `pos += vel * t.deltaTime`；❌ `acc += t.deltaTime` 与 1/60 混比；❌ `v += a * t.deltaMS`（未 ÷1000）；❌ 重复换算。✅ 唯一合法：`deltaMS ÷1000`；备选 `deltaTime × (1/60)`（须注释）。

### 4.2 物理承继清单（10 模块 · 缺一即补）

| # | 模块 | 数学形式（既有规格） | PixiJS 集成位置 |
|---|---|---|---|
| 1 | 时间步进 | h=1/60 + 累积器 + 钳 50ms + 插值 α | ticker 回调（§4.1） |
| 2 | 粒子积分 | 半隐式欧拉：v←v+(f/m)h；x←x+vh | stepPhysics 内 |
| 3 | 空间变阻尼 | k(r)=0.10−0.08·S(r)；c(r)=0.92−0.14·S(r)；S=smoothstep(0.50,0.88) | stepPhysics 内 |
| 4 | 各向异性 | c_rad / c_tan = c ± 0.04·S | 速度分解径向 / 切向 |
| 5 | 无散度流场 | Curl-Noise：w=∇×Ψ，上限 6px/s；LUT 64×64 @30Hz | 力项 |
| 6 | 生命周期 | 渐入 0.6s → 保持 → 末 20%τ 渐出；τ∈[40,120]s | 推 age |
| 7 | 稳态回收 | α≤0.01 或超 1.25·R95 → 回收重生 | 回收队列 |
| 8 | 边界软化 | Q(r)=smoothstep(0.82,0.98)；β_max=8px/s | 速度修正项 |
| 9 | 驻留运动 | M0 涟漪 / M1 流场 / M2 尘埃 / M3 脉线逸散（§5） | **渲染层叠加**（不污染物理态） |
| 10 | 渲染合成 | x_render = x_phys + (x_target−c*)·s(t) + drift(t)；余韵斜坡 0→40%@2s→100%@8s | 写回前合成 |

> 迁移不得把物理层简化为「lerp 到目标」或「每帧固定偏移」。

### 4.3 容器与渲染（ParticleContainer）

```js
const particles = new ParticleContainer({
  dynamicProperties: {
    position: true,    // 【必须】物理位置逐帧上传
    vertex: false, rotation: false, color: false,
  },
  roundPixels: true,   // 像素块锐利（呼吸档位 A：量化）
});
```

- 静态属性只在 `container.update()` 时上传；**修改静态属性或粒子列表后必须调用 `update()`**。
- 粒子增删用 `addParticle / removeParticle / addParticleAt / removeParticleAt / removeParticles`；不得用 `addChild` 等。
- 剥离高级功能（filter / mask / 嵌套不可用）→ 需要时用外层普通 Container 包裹。
- **roundPixels 档位：A 量化**（§9-7）；涟漪透明度载体不受其影响。
- **tint 过渡：S1 静态 + ≤10Hz 节流 `update()`**（§9-8）；过渡时长 2.5–3.5s 与放映对齐。
- **蛛网连线：冻结**（§9-4）——不画任何线；「蛛网状」= 逸散形态（§5.2 M3）。

### 4.4 帧预算（验收）

| 项 | 目标 |
|---|---|
| 持续帧率 | ≥ 55 fps |
| P95 帧时 | ≤ 18 ms |
| 物理 step | ≤ 4 ms |
| 写回 + 上传 | ≤ 3 ms |
| 渲染 | ≤ 6 ms |

- 隐藏页：rAF 停发 → ticker 停摆；回前台首帧大 deltaMS 被 50ms 钳制吸收，**不得**「瞬移补偿」。
- 轮换错峰：与放映状态机对齐，过渡期不与满负荷动画叠加。

## §5 · 驻留形态与生成完整性（v2.2 / v2.4 定稿）

### 5.1 生成序列完整性（修复「半程突变」）

**缺陷定性**：生成（扩散 → 装配）到中途画面跳变至成品态 = 序列完整性缺陷（工程问题）。

**嫌疑清单（先证伪再修）**：

| # | 嫌疑 | 特征 |
|---|---|---|
| X1 | 包络截断：位置被直接写终态 | 单帧统一大位移 |
| X2 | 状态机提前切换（固定计时器而非完成度驱动） | 切换帧 = snap 帧 |
| X3 | 帧依赖跳步：帧计数推进 / 长帧一次跳完 | 60 / 120Hz 行为不同 |
| X4 | 过渡段丢失：「边缘先散核心后散」只播一半 | 后段缺失 |
| X5 | 粒子池重建：切换时位置整体重置 | snap 伴随卡顿 |
| X6 | 缓动错配：前缓后冲，后半 1–2 帧冲线 | 「一半 → 瞬间完成」 |

**证据项**：G1 完成度曲线（RMS 距离平滑单调）；G2 帧差尖峰（P99 > 3× 中位数 = 突变帧）；G3 代码审计 + 双帧率对比。

**修复规格**：

- F1 全序列由统一时间包络 p(t)∈[0,1] 驱动（固定步长内推进），禁帧计数；
- F2 切换 DWELL = p≥0.995 且完成度校验过阈；
- F3 任何阶段禁止直接写终态位置；
- F4 snap 门限：单帧位移 P99 ≤ 3× 前一秒中位数；
- F5 重生粒子出生点须在装配轨迹上游；
- F6 缓动 S 形；后段（p∈[0.6,1]）时长 ≥ 全程 35%。

### 5.2 驻留运动叠构（M0–M3 · 修订定稿）

**M0 涟漪（升级 · 替代原全域缩放）**：

`u(r,t) = A · W_b(r) · sin(2π·t/T − 2π·r/λ + φ₀)`

- 相位随半径延迟 → 波峰以相速度 v=λ/T 向外传播（「一圈圈涟漪」的数学本体）。
- 参数：λ=56px（36–96）；T=8s（6–12）；A=0.5%（0.3–0.9%，美术校准）；W_b=smoothstep(0.10,0.35,r)（中心保护树轮廓）；φ₀ 每画次随机。
- 载体：**V3 组合（V1 低幅位移 + V2 透明度辅助）**（§9-9）；V2 幅度 ±2–4% 压「哑光」红线。

**M1 相干流场**：U₀=0.3 / U₁=6px/s；空间低频 + 时间低频。

**M2 周边尘埃**：占比 5%（§9-10）。

**M3 脉线逸散（升级 · 替代原「边缘蒸发」）**——「蛛网状向外逸散」的正法定稿：

> 生成完成后，四周先按蛛网状（丝缕）向外逸散；**哪怕生成后也不稳定**。

- 术语：脉线（streakline）= 同一源点连续释出粒子在某一时刻的连线（烟缕的学名）。
- 三要素：① 径向外流：r∈[0.72,1.05]，W_e=smoothstep(0.72,0.92,r)，U₀=5px/s（3–8）；② 成束丝缕化：2–3 尺度相干噪声调制，丝缕宽 / 间距 80–160px，时间尺度 >10s（禁闪烁）；③ 网状交织：两套斜交丝缕场叠加，设密度上限。
- 持续性：逸散 → 回收 → 采样层补充；**供给—逸散平衡**，永不耗竭、永不冻结。
- 时序：边缘先行、中心最后 / 最弱。

**余韵斜坡**：0→40%@2s → 100%@8s。

### 5.3 红线与验收

- 反 boil；禁发光；中心树轮廓区保持清晰（中心 std 沿用既有约束）；丝缕相干（空间低频 + 时间低频）。
- 涟漪验收：0.25× 慢放——波纹向外传播方向明确；像水面微涟，不像整块缩放、不像抖动；像素块无灰边。
- 逸散验收：30s 录屏——≥2–3 束丝缕外漂；单束存活 ≥10s；无环形硬边界、无「静止瞬间」；主观：「哪怕生成后也不稳定」成立。
- 生成验收：完成度曲线光滑无尖峰；后段可感知；p 达 100% 前不得进 DWELL。
