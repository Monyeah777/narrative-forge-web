## 0 · 摘要

「自动放映（展览循环）」落地：加载即开演 → catalog 固定顺序 → 停留 8–12s → 边缘先散/核心后散 →「B 核最先凝」的交接过渡 → 循环。

配套：三态性能纪律（带数字）、reduced-motion 不轮换、隐藏即停、合规闭口的放映启停、图注真值更新。**无删除**；全部新增带回退开关（见附录 A）。

> 本版相对草案 v1 的实质增补：①放映启停（合规闭口）；②键盘/指针分权（焦点严格档）；③aria-live 随状态切换 + 启停控件置 tab 序首位。

## 1 · 修宪：旧锁显式修订（3 条）

> **落库要求**：将《手册》原句替换为新条款原文，并在修订记录登记；旧句移入变更历史，标注「被《自动放映 · 修订包》v1.0 替代」。

### R1｜替代「不要加（自动）轮播」

**新条款原文：**

> 深空档案馆艺术区启用『自动放映』：加载自动开演，catalog 固定顺序轮换；停留 8–12s、过渡 2.5–3.5s（入 manifest，确定性可复现）。任意交互即接管：hover 暂停（离开 +1.5s 恢复）；点击/导航进入手动，静置 30s 恢复；键盘焦点进入即停且不自动恢复（仅显式操作恢复）；提供图注级文本『放映启停』（持久暂停、不自动恢复）；prefers-reduced-motion 不轮换。不设重放按钮；可见控件以导航为主，放映启停为注记级文本。

**理由：**
1. 单幅全幅展示、内容全可见，与 NN/g 批判的多消息促销轮播不同源［9］；
2. 8–12s 与 NN/g 判死的 5s 档拉开距离，与博物馆注视研究（中位 17s）相容，取克制下界［9］［10］；
3. 轮换 >5s 触发 WCAG 2.2.2，须机制化暂停——已闭口［2］；
4. 焦点/悬停规则对齐 APG［1］。

**回退**：`autoplay.enabled=false`（回单幅手动档）。

### R2｜修订「散点到装配·仅一次」

**新条款原文：**

> 装配纪律：每幅作品每次登场仅装配一次；停留期不重播、不重算；任何操作不触发二次装配（无重放）。轮换『交接』过渡不属于重放。既有显式交互（点击重组/驱离/彩蛋）权限不变，自动放映不得调用。

**理由**：保留原锁『反重复』精神，把「仅一次」作用域明确为「每幅每次登场一次」，消除与轮换的语义冲突。

**回退**：关闭自动放映 → 行为等同旧锁。

### R3｜修订「成画即停 rAF」→ 三态性能纪律 v2

**新条款原文：**

> ①过渡态：全速 rAF，目标 60fps，脚本 ≤10ms/帧；②停留态：低耗微动 ≤30Hz，脚本 ≤2ms/帧，零重算、零每帧分配；③不可见态：rAF=0、计时冻结、恢复不追赶；④reduced-motion：静态、无装配动画。

**理由**：轮换=持续动效，旧规失效；以三态替代并给可测数字（§5）［5］［6］［8］。

**回退**：`motion.discipline=classic`。

## 2 · 放映状态机与时序（确定性）

- **状态链**：`LOAD → INTRO(首幅装配·显影 2.4s) → DWELL(8–12s) → HANDOVER(2.5–3.5s) → DWELL → …`；交互子状态见 §6 表。
- **顺序**：catalog 固定数组（示例 dallas→scotland→met→…，以现有 catalog 为准）；整轮后回首幅；接缝间奏默认关（拍板项 2）。
- **参数**：`dwell ∈ [8,12]s（默认 10）`、`transition ∈ [2.5,3.5]s（默认 3.0）`、`seed`、`T_idle=30s`——全部入 manifest，运行时不得掷骰子。
- **图注**：随幅更新（真值），交接中段 ≤300ms 换新；`aria-live`：自动中 off、停止时 polite［1］。
- 无进度条、无重放按钮。

## 3 · 过渡「交接」规格

**硬不变式（验收断言）：**

1. 释放排序：`delay_out = D_out·(1 − r̂) + ε`（边缘先散、核心最后；ε=±5% 种子噪声）。
2. 向外漂：自由段外向漂移 `v_drift ≤ 0.3·vmax`。
3. 重组：`delay_in = D_in·r̂`，量化 4–6 波（分波抵达）；尾段阻尼渐强（软收束）。
4. 交接：B 核起凝 = A 核起释 ±0.2s；交叠窗 0.6–1.2s；**禁止全空帧**。
5. 轨迹：直线+轻弧（弓高 ≈4–8% 弦长，种子化流场定向）；末端速度→0（「落」，无回弹）。
6. 禁 `snapAll`：过渡路径零调用；单帧位移 ≤1.5·vmax·dt（加断言）。
7. 时长：D_out+D_in+交叠 = 2.5–3.5s。

> 起手值待 bench 校准；不变式不得放宽。

## 4 · 视觉规格

- **显影组（默认）**：damp↑、vmax≤≈4、2.4s 档、分波、软收束；「凌厉」= 设置对照。
- **像素块**：哑光实心、整数像素对齐（设备像素坐标 round）、关平滑、禁 shadowBlur/叠加发光；尺寸 A/B 起手 2 vs 3 设备像素［7］。
- **初始云**：先审计现状 seeding（禁猜）→ 切「画区中心云」；验收：中位装配距离 ≤原值×0.6（起手，bench 定稿）。可选 P2：云密度叠亮度先验。
- **外围尘埃（活的黑）**：低 alpha、无装配职责；停留期微动载体。
- **画区 ±10% A/B**：位置不动，仅参数化。
- **彩度三版**并入同批裁决（第三版「降饱和豁免」待拍板）。

## 5 · 性能纪律 v2（数字 + 量法）

| 相 | 刷新 | 脚本预算 | 断言 |
|---|---|---|---|
| 过渡 | 60fps | ≤10ms/帧（p95≤12ms） | 掉帧<5%；无 >50ms 长任务 |
| 停留 | ≤30Hz | ≤2ms/帧 | 零重算；零每帧分配 |
| 不可见 | 0 | — | rAF=0；恢复不追赶 |
| reduce | 静态 | — | 无自动轮换 |

- **量法**：DevTools Performance 每相 30s×3；报 p50/p95、掉帧率、长任务、rAF 计数；10 轮循环内存零增长。
- **B4 衔接**：未覆盖常驻动效 → 新增 **B4.1** 子门禁（即上表四态）。
- **可选**（评估后启用，不默认）：静态层离屏烘焙、分层画布、`alpha:false`、差异渲染［7］。

## 6 · 合规映射与偏差登记

| 要求 | 机制 |
|---|---|
| 可暂停/停止（WCAG 2.2.2［2］） | 图注级『放映启停』（常驻、持久暂停、不占焦点）+ hover 暂停 + 点击接管 + 键盘通道 |
| 焦点即停、非显式请求不恢复（APG［1］） | 焦点进入停；仅显式操作恢复 |
| 悬停即停（APG［1］） | hover 暂停；离开 +1.5s 恢复 |
| 启停控件（APG［1］） | 同『放映启停』；展区 tab 序首位、标签随状态切换 |
| reduced-motion（［4］） | reduce=静态、不轮换、无装配动画；手动切换=瞬切或 ≤400ms 淡切 |
| 隐藏即停（［8］） | visibilitychange + IntersectionObserver 双通道 |
