## 档① dart-thinning（默认 · 开 S2 用这条）

**谱系。** Cook 飞镖 → Bridson 2007 网格加速（cell ≈ `r/√n`，active list，环带 `[r,2r]`，每点最多 k≈30 次）。变密度时把半径换成场：`R_local = s0·√(Wmax/W(p))`，与手册 §1#3 / §3.3 一致；边缘/中心间距 ≈ √(W0/W1) ≈ **1.94×**。

**和 Bridson 原文的差别（必须守手册，不能抄 demo）。**

| | Bridson 2007 | 手册 §3.4 / §3.7 |
|---|---|---|
| 遍历 | 随机抽 active list | **种子洗牌后的固定顺序**（或 index 序，二选一锁死） |
| 计数 | 铺满域，N 不精确 | 二分 `s0`，接受数 **50k ± 5%** |
| 半径 | 常半径 r | `R_local(p)`，对已接受点做**真距离**检查 |

随机 active list 难双跑哈希。S2b 按手册定序，不要把 Bridson 的「随机抽 active」写进现网脚本。

**禁止。** 「逐点独立随机半径、不做邻域距离检查」= 加权白噪声。手册 §3.4 已禁。现网 `scripts/sample-painting.py` 的 3 轮亮度缩放排斥也不是 dart-thinning。

**纸面量（Dallas 100k 场，S0 数，不新采样）。** 合格像素 ≈ 1.85e6，`c*≈(0.5,0.5)`，`R95≈0.599`。`s0 ≈ 0.54·√(A/N)`，A≈1（归一化幅面）、N=5e4 → `s0≈0.0024`（约 2.9 px @1200 宽）。中心 `R_local≈s0`，边缘 ≈1.94 `s0`（约 5.6 px）。用 S0 四带面积对 `W(r)` 做中点近似，均匀合格像素的拒绝接受率约 **0.40**。因此「5×N ≈ 250k **带权候选**」指的是**接受后的池**，不是 250k 次均匀抽签；约 0.40 接受率时均匀抽签要到 ~6.3e5。S2a 日志必须同时记：抽签数、接受数、接受率。池不够再升到 10×N 或降 `s0`。

**可行性。** 高。离线 Python + numpy 网格即可，不引新运行时依赖（与 Pixi「无新依赖」一致；S0 已避开 scipy）。S2a/S2b 走这条。不在本闸写脚本。

## 档② 加权样本消除（升级 · 休眠）

**已核。** Yuksel 2015：贪心按邻域权消点，**直接指定输出 N**，不必先给泊松半径；任意域；蓝噪声比飞镖更干净；**不保证最大覆盖**。cyCodeBase `WeightedSampleElimination::Eliminate`：输入点数 > 输出点数；可换 `weightFunction(p0,p1,dist2,d_max)`；默认权 + weight limiting（α/β/γ）；MIT。

**「加权」有两义，不要混。**

1. 算法名：权来自**邻点距离**（谁该先被消）。
2. 手册 `W(r)`：径向**重要性**。

Yuksel §5.2 图 12 用非对称距离做重要性：`d̂ij = dij(3−2Ii)`。官方文档的自定义 `weightFunction` 能接 `W(r)`，但**默认权函数不会自动读径向场**。输入必须先按 `W(r)` 造好（S2a 拒绝采样），消除只是选子集。

**「adaptive / progressive」也不是变密度。** 论文里的 progressive = 按消除逆序排列，让前缀子集仍是蓝噪声（渲染里逐点加样本）。不是 `W(r)` 场。

**短板（原文自己写了）。** 消除**不插入新点**，补不了输入里没有的洞。S2a 候选质量仍决定 §8#2。

**可行性。** 升级档可用：要精确 50k、① 的 `s0` 二分抖、或 §8#1/#2 在默认档不过时再开。不要把 C++ 头引进浏览器。若 S2c 触发升级：用 Python 按伪代码重写（numpy + 堆），或把 MIT 头只放进离线 `scripts/`，**现网零新依赖**。本闸不升级。

## 休眠④ SOT / ⑤ 最大空圆 / ⑥ Lloyd-lite

**④ Sliced OT。** Paulin et al. 2020，官方 C++：[loispaulin/Sliced-Optimal-Transport-Sampling](https://github.com/loispaulin/Sliced-Optimal-Transport-Sampling)。目标是高维 MC / 球-立方体均匀点，不是 2D 径向点绘。README 写明 demo 生成 **uniform** 样本。比 ①/② 重，且与「可解释 + 双跑哈希 + 无新依赖」摩擦大。保持 `post.ot=off`。手册已删「RG 散射 / 随机牛顿」——本闸同意，不再找回。

**⑤ 最大空圆。** Kanamori et al. 2010：在 Delaunay 最大外接圆圆心插入；可加权半径做自适应；可指定点数。Yan & Wonka 2013 *Gap processing for adaptive maximal Poisson-disk sampling*（Cui 文也引）是空隙几何的另一条。手册用法是**残留空洞定点修补**，不是整幅重采样。触发：目检或 NN p99 > 1.8×median。S0 三幅 100k 的 p99/median 已 ≤1.8，16px 空格已是 0——⑤ 对**现网点**不是主药；S2c 换手册口径后再看。Delaunay 逐插对 50k 要堆，只许离线。

**⑥ Lloyd-lite。** Secord 2002 已写：无权重的 Lloyd 会抹平色调。现网脚本注释同一句。手册只许 2–3 轮、位移封顶、默认关。S2 禁止用 Secord 迭代当细化主路径。

## 面积元（S2a 必避的坑）

| 方法 | 官方位置 | 和本件的关系 |
|---|---|---|
| 拒绝采样 | 手册 §3.3；Devroye / von Neumann | 均匀像素 → `P=W(r)/Wmax`。分布正确，接受率随 `E[W]` 变。5×N 计的是**接受池**。 |
| 逆变换 / CDF-LUT | 手册 §1#8 保留 | 与拒绝采样同分布，W 便宜时更快。LUT 必须按**合格像素面积元**建，不能按带宽点数建。 |
| Vose alias (1991) | 离散 O(1) | 像素网格上可用。`numpy.choice(..., p=)` 是同一类，**不是** dart-thinning。 |
| 现网 | `sample-painting.py`：`w=0.6+0.4·L^1.2` + `rng.choice` | 亮度离散抽样。S0：中心/边缘 ≈1.00×。**不得**把这套权再喂给 S2。 |

S2a 权只许 `W(r)=0.2+0.8·e^(−2.5·r)`。`c*` / `R95` 按 §3.1 从合格像素算，写入 meta。暗部仍 `L<0.19`（调色板/掩膜红线，不改）。不要「亮度 × 径向」叠权，除非作者改手册。

候选生成与细化是**两段**（§1#9），不是二选一。S2a 只交带权候选 + 分带密度 + 哈希；细化是 S2b。

### #5 补核（2026-09-12 · 不过不行）

手册积分 `v←(v+k·(T−x))·c` 的一步矩阵：

`[e′ v′]ᵀ = [[1−ck, c], [−ck, c]] [e v]ᵀ`

特征式 `λ² − (1+c−ck)λ + c = 0`。判别式 `D=(1+c−ck)²−4c`。`D<0` 复根 = 振荡。

临界（`D=0`，`(0,1)` 根）：`c*(k) = 1/(1+√k)²`。

| 点 | k | 手册 c | D | 含义 |
|---|---:|---:|---:|---|
| 中心 | 0.10 | 0.92 | −0.338 | 欠阻尼。24px 休眠 1.68s，过零 10 |
| 边缘 | 0.02 | 0.78 | −0.007 | 几乎临界 |

Hallauer（LibreTexts §9.8）：欠阻尼 2% 调节时间 `t_s≈4/(ζω_n)`；ζ=1 无超调且最快不振荡。Chou 2015 把**同一条** `v+=k·e; v*=c` 标成无法按频率/半衰期独立点参——正是手册中心对的问题。
