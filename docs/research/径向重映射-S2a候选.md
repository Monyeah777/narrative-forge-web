# 径向重映射 · S2a 带权候选

手册：`docs/NF_径向重映射_总结版最终方案_v2.0.md`  
脚本：`scripts/radial-s2a-candidates.py`  
证据：`painting/radial-s2a.json`  
隔离：`painting/radial-s2a-{dallas,scotland,met}-50k.u16`（裸 `<u16le x,y>`，**无 NFPT 头**，现网不会误读）

本闸 = 阶段 1 拒绝采样。**没有** dart-thinning / WSE / 圆填充。**没有**写现网 bin。弹簧 / 调色板未动。

## 做法

1. 与 S0 同一场：1200px 预览、`L≥0.19` 合格像素、`c*` / `R95`（§3.1）。
2. `W(r)=0.2+0.8·e^(−2.5·r)`，`Wmax=1.0`。均匀抽合格像素，`u < W/Wmax` 接受（有放回）。
3. 接到 **250k**（5×N）后，PCG64 洗牌取前 **50k** 作为中间产物。
4. 同种子再跑一遍，`pool_f64` / `mid_f64` / `mid_u16` 必须一致。
5. 跑前跑后核对现网五文件 sha，有变就失败。

种子 `0x53324131`（十进制 1395802417），`numpy.random.PCG64`。

S0 现网 100k 同口径是 ≈1.00×。权换成 `W(r)` 之后，分带密度已过门槛，但还没到设计 3.76×（3.76 是 W(0)/W(1) 端点，不是带平均）。带平均大约 2.4–2.6×，与 S1 纸面估计一致。

Dallas 50k 分带点数：8652 / 17547 / 17050 / 6751。合格像素密度 0.0461 → 0.0312 → 0.0228 → 0.0192，中心密、边缘疏。

拒绝采样：250k 接受 / 655360 抽签 = **0.38147**（S1 估 ~0.40）。`mean_W≈0.395`。5×N 指接受池，不是抽签次数。

NN p99/median 2.57–2.86，**不过** §8#2。16px 空合格格 Dallas 17（0.24%）。这是没有细化的加权白噪声，手册 §3.4 已预告。S2b 默认档的事。
