## 检索（过闸后才写代码）

§7#3 / #4 五搜，引用 Fiedler 2004、Integration Basics、Driscoll 2016、Gustavson 2005/2011。详见备忘 S3 段。

要点（执行用）：

1. 累加器只消耗整份 `h=1/60`。显示 120Hz 时两帧一步，不把 `k,c` 乘显示 dt。
2. 半隐 Euler：`v ← (v + k(r)·(T − x))·c(r)`；`x ← x + v`。
3. `c(r)` 是定步长系数。禁止 `pow(c, dt_display)` 改写（会改手册数）。
4. Gaffer 原文钳 0.25s；手册 50ms。本闸跟手册。
5. Simplex 3D 双路自写（Gustavson / 公有域），不 vendor FastNoise-Lite。
6. Δ 只加在渲染位，不进积分器。

## 开关（默认 = 手册 §4 全开）

| 键 | 默认 | 作用 |
|---|---|---|
| `field` | on | `k(r)/c(r)`；关则全体用中心常数 0.10 / 0.92 |
| `anisotropy` | on | `c_rad=c+δ`，`c_tan=c−δ`，`δ=0.04·S(r)` |
| `drift` | on | Simplex 双路，`A(r)=5·smoothstep(0.55,0.92,r)` |
| `noiseLut` | on | 64×64 @30Hz + 双线性；关则逐点 Simplex |
| `sleep` | on | `\|v\|<0.05` 且 `\|x−T\|<0.5`；不 `lockTo` |
| `gating` | on | INTRO/HANDOVER Δ×0；DWELL ×1；REPEL ×0.5 |
| `interpolate` | on | Gaffer `lerp(prev, curr, acc/h)`，只影响渲染 |
| `reducedMotion` | off | 全静（积分与 Δ 都停） |

现网弹簧 **不是** 本模块的一个档。0.055 仍只在 `nf-spring.js` / `index.html`。

## 场（锁定）

`S(r)=smoothstep(0.50,0.88,r)`  
`k(r)=0.10−0.08·S` → 中心 0.10 / 边缘 0.02  
`c(r)=0.92−0.14·S` → 中心 0.92 / 边缘 0.78  

`r` 从目标 T 用 S2 Dallas meta：`c*=(0.5,0.5)`，`R95=0.599042`，分析幅 1200×1540。与采样同一归一化距离。
