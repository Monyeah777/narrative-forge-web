## 场

`k(r)=0.10−0.08·S(r)` **未改**（中心 0.10 / 边缘 0.02）。

手册 `c(r)=0.92−0.14·S` 仍可开关回到。默认改用本积分器的离散临界：

`c*(k) = 1 / (1 + √k)²`

来自 `v←(v+k·(T−x))·c`，`x←x+v` 的特征多项式 `λ² − (1+c−ck)λ + c = 0`，令判别式为 0，取 `(0,1)` 根。

| r | k | 手册 c | D(手册) | c* | D(c*) |
|---|---:|---:|---:|---:|---:|
| 0 / 0.5 | 0.10 | 0.92 | **−0.338**（复根=振荡） | **0.577** | 0 |
| 1.0 | 0.02 | 0.78 | −0.007 | **0.768** | 0 |

中心手册对 `(k,c)` 欠阻尼，这是 #5 先失败的原因，不是 24px 选大了。Allen Chou 2015 对同一条递推写过：k 与乘性 c 不能当两个独立手调旋钮。

积分器公式未改。只换与 k 配对的 c。各向异性的 `c_rad` 不得大于 `c*`（否则径向又欠阻尼）。
