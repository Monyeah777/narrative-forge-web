# 径向重映射 · S2b 默认 dart-thinning

手册：`docs/NF_径向重映射_总结版最终方案_v2.0.md`  
脚本：`scripts/radial-s2b-thinning.py`  
证据：`painting/radial-s2b.json`  
隔离：`painting/radial-s2b-{dallas,scotland,met}-50k.u16`（裸 u16，无 NFPT）

本闸 = 阶段 2 默认档 ①。S2a 同一 250k 池（`pool_f64` 对得上），按同一 PCG64 洗牌序遍历。**没有**开 ②/③。**没有**写现网 bin。弹簧 / 调色板未动。

## 做法

1. 再生成 S2a 250k，校验 `pool_f64`。
2. `R_local = s0·√(Wmax/W(p))`。距离在**分析图像素**里量（`A_mask` = 合格像素数）。禁止逐点随机半径。
3. 网格 `cell = s_max`。接受：与已接受点距离 ≥ `R_local(p)`。
4. `s0` 初值 `0.54·√(A_mask/N)`，二分。第 3 轮若仍超 ±5%，续二分到进门再锁定（Dallas 第 3 轮 −10.4%，+1 轮到 +1.2%）。
5. 锁定 `s0` 再 thin 一遍，下标必须一致。
