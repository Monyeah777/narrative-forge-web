## 成因初判

1. **权函数错位（主因）**  
   现网按亮度采样。高调画作几乎全图合格，径向密度被抹成 ≈1×。手册要的是 `W(r)=0.2+0.8·e^(−2.5·r)`，设计中心/边缘 **3.76×**。

2. **细化缺位**  
   现网是加权无放回抽样 + 3 轮排斥 + 16px 填洞。没有 dart-thinning / 加权样本消除 / 单趟圆盘填充。NN p99 已经达标，说明「16px 格空了」不是当前主病；缺的是变密度蓝噪声。

3. **空洞口径不一致**  
   现网「空洞」= 16px 合格格空置（100k 已是 0）。手册「空洞」= NN p99 与肉眼空圆。S2c 要用手册口径复测，不能只看 16px 格。

4. **点数冲突（未改）**  
   本件 S2 输出 50k；现网与 Pixi I-2 基准是 100k。S0 **不改档**。S2 开闸前必须作者确认：隔离 50k，还是改现网。

5. **物理冲突（未改）**  
   本件 §4 是 `k(r)/c(r)` 平滑场。现网锁死弹簧 **0.055 / 0.90 / vmax 10**。S3 前不得静默改弹簧。
